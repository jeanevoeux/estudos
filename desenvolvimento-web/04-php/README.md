
# 04 - PHP

Essa pasta contém um projeto desenvolvido para praticar os primeiros conceitos da linguagem PHP.

## Projeto: Formulário de Saudação

O projeto consiste em um formulário onde o usuário informa seu nome e sua idade, após confirmar o envio, o PHP recebe os dados e apresenta uma saudação personalizada, informando também se a pessoa é maior ou menor de idade.

### Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PHP

### Conteúdos praticados

- Criação de formulários HTML.
- Envio de dados utilizando o método POST.
- Recebimento de informações com $_POST.
- Declaração e utilização de variáveis.
- Estruturas condicionais (if e else).
- Validação de dados.
- Utilização de trim(), filter_var() e htmlspecialchars().
- Manipulação de elementos HTML com JavaScript.
- Criação de modal de confirmação.
- Integração entre HTML, CSS, JavaScript e PHP.

## Como executar

1. Instale o XAMPP.
2. Abra o PowerShell na pasta do projeto.
3. Execute o comando:

   & "C:\xampp\php\php.exe" -S localhost:8000

4. Abra o navegador e acesse:

   http://localhost:8000
