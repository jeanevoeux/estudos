## 01 - HTML5

Essa pasta reúne estudo e projeto desenvolvido utilizando HTML5.

## Projeto: Minha receita favorita

O projeto consiste na criação de uma página web estática que apresenta uma receita de bolo de chocolate.

A página organiza as informações da receita em diferentes seções, permitindo a navegação entre elas por meio de links internos.

## Conteúdos abordados

- Estrutura básica de um documento HTML5.
- Títulos e parágrafos.
- Links e navegação interna.
- Inserção de imagenm.
- Listas ordenadas e não ordenadas.
- Formulário.
- Campos de entrada (input e textarea).
- Botão.
- Elementos semânticos (header, nav, main, section e footer).
- Atributos HTML (id, name, alt, required e placeholder).

## Como executar o projeto

1. Acesse a pasta minha-receita-favorita.
2. Abra o arquivo index.html em um navegador.
3. Navegue entre as seções da página utilizando o menu.

## Tecnologias utilizadas

- HTML5
