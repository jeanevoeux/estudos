# Estudos de Desenvolvimento Web

Este repositório reúne atividades e projetos desenvolvidos durante os estudos da disciplina de Desenvolvimento Web.

## Projetos Desenvolvidos

### 01 - HTML
- Projeto: Minha Receita Favorita.
- Criação de uma página HTML para apresentar uma receita de bolo de chocolate.
- Conteúdos praticados: estrutura HTML, títulos, parágrafos, listas, imagens e links.

### 02 - CSS
- Projeto: Site de Notícias.
- Criação de uma página de notícias com três matérias e imagens.
- Conteúdos praticados: seletores CSS, cores, fontes, margens, espaçamentos e organização dos elementos na página.

### 03 - JavaScript
- Projeto 1: Jogo de Adivinhar o Número.
- Projeto 2: Consulta de Ditados Populares.
- Conteúdos praticados: variáveis com let e const, condicionais, funções, eventos, manipulação do DOM, Math.random(), fetch(), JSON, consumo de API e tratamento de erros.

### 04 - PHP
- Projeto: Formulário de Saudação.
- Criação de um formulário para receber nome e idade, processar os dados e apresentar uma mensagem ao usuário.
- Conteúdos praticados: variáveis, formulários com POST, recebimento de dados com $_POST, condicionais, validação de dados, integração entre HTML, CSS, JavaScript e PHP, além de modal de confirmação.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- JSON
- API externa

## Objetivo

Organizar os exercícios e projetos desenvolvidos durante a disciplina, documentar os conteúdos estudados e acompanhar a evolução do aprendizado em Desenvolvimento Web.
