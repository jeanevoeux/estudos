# Projeto JavaScript - Jogo de Adivinhar o Número

## Sobre o projeto

Este projeto consiste em um jogo simples no qual o computador escolhe um número aleatório entre 1 e 100, e o jogador precisa descobrir qual é.
Durante o jogo, são exibidas mensagens informando se o número escolhido é maior ou menor que o número secreto.

## O que foi utilizado

- HTML5 para estruturar a página.
- CSS3 para estilizar o jogo.
- JavaScript para criar a lógica do jogo.
- Variáveis para armazenar informações.
- Condicionais (if e else if) para verificar os palpites.
- Funções para executar as ações do jogo.
- Math.random() e Math.floor() para gerar números aleatórios.
- Manipulação de elementos HTML com JavaScript.

## Como executar

Abra o arquivo `index.html` no navegador para jogar.
