## Projeto JavaScript - Jogo de Adivinhar o Número

Este projeto consiste em um jogo simples no qual o computador escolhe um número aleatório entre 1 e 100, e o jogador precisa descobrir qual é.
Durante o jogo, são exibidas mensagens informando se o número escolhido é maior ou menor que o número secreto.

## O que foi utilizado

- HTML5 para estruturar a página.
- CSS3 para estilizar o jogo.
- JavaScript para criar a lógica do jogo.
- Variáveis para armazenar informações.
- Condicionais (if e else if) para verificar os palpites.
- Funções para executar as ações do jogo.
- Math.random() e Math.floor() para gerar números aleatórios.
- Manipulação de elementos HTML com JavaScript.

## Como jogar

Abra o arquivo index.html no navegador para jogar.

## Projeto JavaScript: Consulta de Ditados Populares

Projeto que utiliza uma API para buscar ditados populares em português e exibir seus significados na página.

### Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- JSON
- API

### Conteúdos praticados
- Declaração de variáveis com const.
- Manipulação do DOM.
- Eventos de clique.
- Funções.
- Requisições com fetch().
- Utilização de async e await.
- Recebimento e leitura de dados JSON.
- Tratamento de erros com try/catch.
- Integração com API externa.

### Consulta de Ditados Populares

1. Abra a pasta consulta-frases.
2. Abra o arquivo index.html no navegador.
3. Clique no botão "Buscar frase" para consultar um ditado popular.
4. O resultado será exibido na página.
