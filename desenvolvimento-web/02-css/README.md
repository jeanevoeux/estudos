# Projeto CSS - Site de Notícias

## Sobre o projeto

Este projeto consiste em um site simples de notícias, desenvolvido para praticar os conceitos de HTML5 e CSS3.
A página apresenta três notícias em destaque, organizadas em um layout simples.

## O que foi utilizado

- HTML5 para estruturar a página.
- CSS3 para estilizar o site.
- Cores, fontes, margens e espaçamentos.
- Flexbox para organizar as notícias.

## Como executar

Abra o arquivo index.html no navegador para visualizar o site.
